# Intent Layer Logs

Runtime logs are written to the bench logger namespace `intent_layer` and persisted in the existing `MCP Usage Log` DocType.

Use:

- `bench --site <site> execute mcp_ui.intent_layer.api.health`
- `bench --site <site> execute mcp_ui.intent_layer.api.refresh_schema`
- Frappe Desk > MCP Usage Log
